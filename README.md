# pgEdge Homebrew Tap

[![CI](https://github.com/pgEdge/homebrew-tap/actions/workflows/ci.yml/badge.svg)](https://github.com/pgEdge/homebrew-tap/actions/workflows/ci.yml)

Homebrew casks for pgEdge tools. The tap carries one cask, `pgedge`,
the
[pgEdge CLI](https://github.com/pgEdge/pgedge-cli).

## Quickstart

Install the CLI:

    brew install pgEdge/tap/pgedge

Upgrade it:

    brew upgrade pgedge

Confirm the installed version:

    pgedge version

The cask installs shell completions for bash, zsh and fish. The
[getting started guide](https://github.com/pgEdge/pgedge-cli/blob/main/docs/getting-started.md)
covers what to do next.

## Issues

Report a problem installing or upgrading through Homebrew in this
repository's issues. Report a bug in the `pgedge` command itself in
[pgEdge/pgedge-cli](https://github.com/pgEdge/pgedge-cli/issues).
